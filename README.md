# jetport-media

Videos y generador de contenido para las redes de Jetport Courier (TikTok, Instagram, Facebook).

- `generador/video.py` — crea videos verticales a partir de un guion JSON (ver instrucciones al inicio del archivo).
- `generador/musica.py` — pista musical original (sin derechos de autor), variable con una semilla.
- `guiones/` — guion de cada video publicado (fecha_tema.json).
- `videos/` — videos finales; Metricool los descarga desde aquí.
- `temas_publicados.md` — registro de temas ya usados, para no repetir.
