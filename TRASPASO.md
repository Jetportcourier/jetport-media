## 10. Cómo usar el repositorio
    git clone https://github.com/Jetportcourier/jetport-media
    pip install pillow numpy scipy --break-system-packages    # + ffmpeg
    python3 generador/video.py guiones/X.json vista.png 7.5    # revisar un fotograma
    python3 generador/video.py guiones/X.json videos/X.mp4     # generar el video
    git add -A && git commit -m "..." && git push              # luego programar en Metricool con la URL raw
Guion JSON: {"musica_semilla": N (0–119), "escenas": [...]}. Tipos de escena:
- "titulo" (arriba, lineas, sub), "texto" (etiqueta, titulo, texto), "punto" (numero, etiqueta, titulo, texto),
  "clip" (archivo, inicio, dur, texto, resaltado, posicion, recorte, con_audio, subtitulos), "cta" (modo "escribenos" opcional).
- Opcionales por escena: "dur", "fondo" (avion | ruta | tienda | cajas), "transicion" (zoom | barrido | ninguna).
- Opcionales del guion: "estilo_caja" (blanco por defecto), "logo", "logo_opacidad", "cierre": false.
El docstring al inicio de generador/video.py tiene el detalle completo.
